# MP4 BG Removal — Verification and Regression Checklist

> Baseline: 2026-10-03; frame-project checks added on 2026-10-04; editing interaction checks updated on 2026-10-06. The original seven checks remain below, followed by checks for the new editor. See [product requirements](PRD.md) and [technical design](TDD.md).

1. Load two MP4 files. Give them different key, crop, trim, output size, background, and output folder settings; switching files must restore each profile. Refresh and verify both uploads, settings, and the last selection remain in the left list. Export one and confirm the other has no output.
2. With a 1280×720 source, select 720×720 and 400×600 output. The fixed white crop frame must have the respective ratio while the source picture retains 16:9; outside edit mode, the chosen crop must fill the source pane without an overlay.
3. Drag and zoom the crop, scrub source and output frames, set an interval with both handles, and use the first/last frame jump buttons. Check that exported frames match the selected interval and crop.
4. Play the source interval without first generating an output preview. Generate an output preview, scrub it, replay unchanged settings without a new job, then change a key or crop setting and confirm regeneration.
5. Add and remove a preview background. Move and zoom the transparent foreground. Check that only the foreground transform reaches export, and inspect the WebP alpha rather than judging only from the checkerboard UI.
6. Save to a non-default directory, verify the actual path, open that folder, and repeat the name to confirm a safe numeric suffix. Confirm failures show FFmpeg stderr and never alter the source MP4.
7. Run `npm test`, `npx tsc --noEmit`, `npm run build`, and `node scripts/smoke-chroma.mjs` with FFmpeg installed. Browser interaction and visual crop geometry require a manual UI check in addition to automated tests.

## Frame-project checks

1. Without generating an editor project, export the selected interval as WebP, separate PNG files, and a PNG atlas. Confirm the PNG sequence is in its own new folder under the one output path shown at right.
2. Select one file in the left list and generate transparent PNG frames. Confirm every source frame occupies one bottom timeline slot and there is no separate saved-project selector. Switch to another file; its timeline must be independent or empty. Switch back and confirm the first edit remains. Close and reopen the editor; there is no duplicate large preview or per-frame position/zoom controls.
3. Use the previous/play/next icon controls and confirm each updates the right preview. Select one tile and use its left and right `+` buttons to insert blank slots at the indicated positions; each adds `1 / output FPS` to edited duration. Shift-click a range, drag it to a new location, and confirm the group keeps its internal order; reverse the range and confirm only those slots change order. Copy one slot and a selected range with Ctrl+C, select a destination, then use Ctrl+V to insert copies immediately after the active frame. Confirm copies preserve order and empty slots, change edited count/duration, and leave original order intact. Check repeat-paste behavior, confirm the toolbar describes the shortcuts without Copy/Paste buttons, and verify shortcuts do not intercept typing in other page inputs. Clear selected slots and confirm they remain in place, preview as transparent, and do not change count or duration. Delete selected slots and confirm edited count and duration decrease by the selected count and `selected count / output FPS`; original count stays unchanged. Undo the deletion and confirm the slots return. Assign a source frame through an empty slot's `+`, including one already used elsewhere. In the right preview, switch Original/Edited and confirm the original source frames remain accessible; a newly loaded project defaults to Edited.
4. Refresh the page. Confirm the left list, selected file, MP4 source preview, per-file settings/background, slot order, empty slots, duplicate assignments, and source-frame pool all return without a separate restore action.
5. Independently switch the right export order between Original and Edited for each of WebP, PNG sequence, and PNG atlas. The preview switch must not alter export order. Confirm cleared slots affect only Edited; deleted slots reduce Edited PNG/WebP/atlas frame counts and WebP duration, while Original still exports every generated frame. Confirm atlas dimensions and transparent padding use the selected order's count.
6. Run `node scripts/smoke-frame-projects.mjs` with FFmpeg installed. It checks saved uploads/profiles, in-place frame generation under one ID, original/edited separation, PNG count, atlas dimensions/padding, WebP duration, and cleanup.
7. In Edited mode, choose K loop-blend pairs and apply. Confirm the new edited count is N−K, duration is (N−K)/FPS, and the final K timeline thumbnails crossfade from the old tail toward the old head. Inspect them in the existing right preview, refresh, and verify they persist. Export Edited as WebP, PNG files, and atlas, then export Original and confirm it still has N unmodified frames. Use Undo blend before another edit and confirm the former edited order returns. Change one slot after blending and confirm the prior blend cannot be undone accidentally. `tests/chromaLoopBlend.test.mjs` covers the saved assets, alpha blend, three export formats, and undo behavior.
8. Click one middle frame, Ctrl-click another, choose K in Selected pair, then Blend pair. Confirm K new thumbnails appear immediately after the earlier selected frame, all old thumbnails keep their order, and edited duration grows by K/FPS. Test both adjacent and nonadjacent choices, the existing right preview, refresh, all three Edited exports, Original export, and Undo blend. Shift-clicking only two adjacent frames also enables Blend pair.
9. Open `Output Edit > Adjust > Position`. Drag the output before clicking Move and confirm the foreground does not shift. Activate Move and confirm a four-way move cursor, then drag to reposition; switch to Mask or Export and confirm dragging is disabled again. In Mask, check the `Show mask` label and distinct Erase/Restore icons. Paint with Hard edge and Soft edge, then use Restore, Undo stroke, and Reset mask. With either brush action active, press `]` and `[` to change brush size by 4 px, respecting minimum and maximum; Ctrl+Z must undo the latest mask stroke. These shortcuts must not intercept typing in text inputs or affect Position. At the minimum brush size, confirm the center reticle stays smaller than the visible brush circle rather than covering it with the browser crosshair. Confirm the erased area stays fixed when scrubbing or playing frames and when switching Original/Edited. Refresh and switch files to verify each file's mask returns independently. Export WebP, separate PNGs, and atlas to verify alpha in every frame; the uploaded preview background must remain visible behind the erased area but absent from exports. Re-uploading the current MP4 must clear its old mask. `tests/chromaOutputMask.test.mjs` verifies alpha composition and source-frame preservation.
10. Move a saved project's `source.mp4` out of its local project directory, refresh, and confirm the left list offers Relink. Choose a different MP4 and confirm rejection without changing the project. Choose the original bytes under a different filename and confirm the source preview, settings, frame slots, and exports return. `tests/chromaSourceRelink.test.mjs` checks the fingerprint match, rejection, and preserved project data. A legacy project that lost its source before fingerprinting requires manual recovery outside this flow.
11. With a saved frame project, select Edited in the Output preview. Start playback from the bottom frame editor and confirm Output shows Pause preview; pause from Output and confirm the editor returns to Play. Start from Output and pause from the editor to verify the reverse direction. The shown frame, counter, slider, and bottom timeline selection must advance or jump together. Pause and switch to Original, then confirm its playback and slider still work. Switching orders stops playback.
12. In the bottom editor, confirm each thumbnail shows its source image ID above the image and its timeline slot number below. Reorder or duplicate a slot and verify the upper ID follows the assigned image while the lower number follows the slot position. Empty slots show `Empty`. Newly generated loop frames show a purple `Loop` label and `L` badge; selected-pair frames show a cyan `Pair` label and `P` badge. The right Output preview shows the same blend type while displaying an Edited blend frame. Older projects without blend-type metadata show a generic `Blend` label and `B` badge. Confirm the badges survive refresh, reordering, and undo. The header describes Ctrl+C/Ctrl+V; the toolbar has no separate Copy/Paste buttons.
13. In the source-frame chooser, confirm deleted or otherwise unassigned source PNGs are marked Unused, singly referenced PNGs are marked Used once, and duplicated PNGs show their exact use count. Check the All, Unused, Used once, and Used multiple times filters; choosing a source PNG should update these counts the next time the chooser opens. Derived blend slots do not count as direct uses of the original source PNG pool.
14. In the edited timeline, place source images with nonadjacent numbers next to each other (for example #048 then #020). Confirm a small amber `!` appears between their thumbnails and its tooltip names both image numbers. Adjacent numbers in either direction (such as #020 then #019), repeated numbers, empty slots, and transitions involving a derived blend image should not show this source-number cue. Reorder or replace a source image and confirm the cue updates immediately.
15. Select an occupied Edited slot and open Edit this frame (or double-click its thumbnail). Move and zoom its image, paint a hard and soft mask stroke, Restore, undo a stroke, and reset the mask. Confirm the per-slot mask stays in the same output-canvas location while the image moves. Toggle previous/next onion skin and opacity; confirm it shows adjacent Edited slots but never appears in Output or exports. Save, refresh, and verify the edit on the timeline thumbnail and Output preview. Export Edited to WebP, PNG, and atlas and inspect the same effect; Original remains unchanged. Copy the slot, edit only the copy, reorder both, then delete and undo one to verify independent slot edits follow their time slots. Replacing a source frame clears its old edit. Cancel from the editor leaves the slot unchanged. `tests/chromaSingleFrameEdit.test.mjs` verifies fixed-mask export, source-image independence, copying, and Original export.
16. Open an occupied Edited slot while a preview background is set in Output Edit. Confirm the single-frame canvas shows it and can switch between original pixel size and fit-to-window, or show the transparency checkerboard. The preview header should always show the Show mask toggle. Paint a stroke with Erase, then switch among Move, Hand, and selection tools; toggling Show mask should switch between the translucent red guide and actual erased transparency without changing the mask. Both onion-skin checkboxes should start off. Verify the canvas CSS dimensions and shown percentage; Show at 100% should display at the output's pixel dimensions, and Fit window should restore responsive sizing. These view controls must not alter exports.
17. In the single-frame editor, switch Preview background among Background image, Transparent pixels, and Solid color. Test black, white, gray, green screen, and magenta; only the preview canvas should change. Select a solid color, move to another Edited slot, and reopen the editor; the selected mode and color should persist for that project. Switch back to Background image and verify its original-size/fit choice also persists. A project with no uploaded background should still permit the other two modes.
18. In the single-frame editor, use the view magnifier to reach 200% or more. The preview window dimensions should stay fixed while both scrollbars become available. With Hand selected, drag the canvas and confirm its scroll offsets change without marking the frame edited. Press V or click Move, drag the frame image, and confirm only its saved position changes. Press H or click Hand and confirm dragging pans again. Hold Space while Move, Erase, or Restore is active to pan temporarily; release it and confirm the prior tool resumes. Erase/Restore left-drag must still paint. Show at 100% and Fit window should reset the view magnifier without changing image zoom or export.
19. Open the single-frame editor and verify the vertical tools stay visible beside the canvas. Choose Move, Hand, Erase, and Restore directly without entering Position or Mask tabs. Press E and R to switch Erase and Restore, including after choosing Move or Hand. Each selection should activate the matching canvas behavior and reveal its controls. In the mask controls, confirm the brush thumbnail and its edge/softness/size label update as the brush settings change, matching Output Edit's preview. While Erase or Restore is active, press `]` and `[` to increase and decrease brush size by 4 px; confirm the slider and thumbnail update immediately and the size stays within its existing limits. With Move or Hand active, these keys should not change brush size. Paint one stroke, press Ctrl+Z, and confirm the same result as Undo stroke without affecting the global mask; Ctrl+Z inside a text field must retain text-editing behavior. At minimum brush size, the center reticle should stay inside the brush circle; Space or middle-button panning must still show the hand cursor. Paint over a detailed part of the source image with Show mask checked: the image detail must remain visible through translucent red. Uncheck it and confirm the actual erased transparency appears; recheck it and switch tools to verify the guide persists.
20. In the single-frame editor, press L and P to switch between freehand lasso and polygon, then draw each around distinct image areas. Polygon corners should have no circular markers. While drawing a polygon, right-click once to remove the last corner and confirm the dashed outline updates; right-click after completion should not alter the selection. Right-click elsewhere in the open single-frame editor and confirm the browser context menu does not appear. Close a polygon near its first point, by double-click, Enter, and Close polygon. Confirm an unfinished path can be canceled and a completed selection has a visible dashed outline. Erase selected and Restore selected must affect only pixels within the selection, show the result in Output after Save changes, and each undo in one step; Ctrl+Z while a selection tool is active must undo the latest applied mask change. Switch to Erase or Restore brush while a selection is active and verify painting cannot change pixels outside it. Deselect or press Esc or Ctrl+D, then paint again to confirm the brush is unrestricted; Ctrl+D must not open the browser bookmark dialog. Cancel the editor after making a selection but before applying any mask change; the selection must not persist or alter exports.
